# Surface brief — lesson workspace

Mode: Operate
Audience: a student solving a C exercise with a lesson and AI beside the editor.
Job: understand the idea, write C, run it, interpret the error, ask for a hint, and mark progress.
Success: the learner can move from reading to running to a corrected answer without leaving the page.

## Direction contract
THESIS: a three-panel study desk, not a course catalogue; the code is the centre of gravity and the lesson/AI orbit it.
OWN-WORLD: warm paper ground, near-black ink, hairline rules, IBM Plex Sans Thai, Kanit only for the brand, compact mono for code, deep moss for success and oxide red for errors.
STORY: read the short idea, try the code, see the console, ask the tutor what the error means.
FIRST VIEWPORT: slim top bar; left lesson column with questions; broad centre editor with a visible console below; right tutor rail with context chips.
FORM: code-led, no comp; the signature interaction is the live run-to-AI context handoff.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
